# Far Ground

Kerbin's ground drawn all the way to the horizon in Kerbal Space Program 1: where the game draws a few big, coarse pieces of
ground far off, Far Ground draws it again on the graphics card at a point every few pixels, from the game's own heights, decals
and land. The short version is on the repository's front page.
